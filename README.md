# Проект: Научиться учиться (Яндекс.Практикум)

Одностраничный адаптивный сайт, созданный в рамках обучения на платформе [Яндекс.Практикум](https://yandex.ru). Проект посвящён современным методикам обучения, техникам тайм-менеджмента и эффективным подходам к усвоению новой информации.

🚀 **[Посмотреть живой проект](https://Andro-Andy.github.io/how-to-learn/)**

---

## 🛠 Технологический стек

* **HTML5** — семантическая разметка страницы.
* **CSS3** — стилизация, позиционирование и анимации.
* **Flexbox** — построение гибких и отзывчивых сеток.
* **Nested БЭМ** — продвинутая файловая структура (Блоки, Элементы, Модификаторы) для масштабируемости и чистоты кода.

---

## 💎 Ключевые особенности и доработки

* **Полный адаптив:** Страница корректно отображается и сохраняет удобство интерфейса на любых устройствах — от мобильных телефонов до широкоформатных мониторов.
* **Интерактивность:** Добавлены плавные CSS-анимации и трансформации (эффекты при наведении, появление элементов), которые делают интерфейс «живым».
* **Семантика:** Соблюдены современные стандарты веб-доступности для лучшего считывания кода поисковыми роботами.
* **Организованная структура:** Использование методологии БЭМ с вложенной (Nested) структурой файлов позволяет легко поддерживать и развивать проект.

---

## 📂 Инструкция по развертыванию

Если вы хотите запустить проект локально:

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com
   ```
2. Перейдите в папку с проектом:
   ```bash
   cd how-to-learn
   ```
3. Откройте файл `index.html` в любом браузере.
